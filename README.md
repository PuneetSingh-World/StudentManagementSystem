# Student Management System

A console-based Core Java application designed to manage, process, and analyze student records using fundamental Java concepts without external frameworks or collections APIs.

## Features

- **Add Student:** Input and store student records with validation for positive IDs, duplicate IDs, age limits, and mark ranges (0–100).
- **Display All Students:** View all recorded students in a formatted tabular layout.
- **Search Student:** Find specific student details using unique Student IDs.
- **Display Student Result:** Calculate overall total, average percentage, letter grade (A+ to F), and pass/fail evaluation per student.
- **Update Student Marks:** Modify existing subject marks with real-time input validation.
- **Class Statistics:** Display class-wide analytics including average percentage, pass/fail counts, and highest/lowest scores.
- **Subject-wise Marks:** View subject mark distributions across all students and output subject averages using a 2D matrix structure.

## Core Java Concepts Applied

- **OOP Principles:** Custom classes, objects, and parameterized constructors using the `this` keyword.
- **Control Flow:** `switch` statements, `while` loops, `for` loops, and `do-while` validation loops.
- **Data Structures:** Fixed-size 1D object arrays (`Student[]`) and 2D primitive matrix arrays (`double[][]`).
- **Methods & Polymorphism:** Method overloading (`calculateAverage`), modular methods with parameters/returns, and explicit type casting.

## Prerequisites

- **Java Development Kit (JDK):** Version 17 or 21 (LTS recommended)
- **IDE:** IntelliJ IDEA, VS Code, or any standard Java IDE
